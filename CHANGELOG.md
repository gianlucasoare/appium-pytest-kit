# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

## [0.1.9] - 2026-03-01

### Added

- First-class API endpoint testing support with `ApiClient`, `ApiResponse`, and `ApiRequestError`.
- Framework scaffold additions for `api/client.py`, `tests/api/test_health.py`, and `api_client` fixture.
- Comprehensive API testing tutorial in `docs/api-testing.md` (beginner to hybrid API+mobile flows).
- `.agent` improvements: operational rules and new `clean-code` skill.

## [0.1.8] - 2026-03-01

### Added

- Stability pack: flake/perf quality gates, quarantine workflow lane, and release hardening.
- Performance telemetry and trend artifacts (`perf-summary.json`, `perf-trend.json`).
- Artifact redaction controls and app-state reset action helpers.
- Local `.agent/` operating system with skills, workflows, ADRs, templates, and playbooks.

## [0.1.7] - 2026-02-26

### Added

- Initial release baseline for `appium-pytest-kit`.
