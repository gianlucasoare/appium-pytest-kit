# Roadmap

Living plan for framework evolution.

## Now (0-4 weeks)

- Stabilize new quality gates (flake/perf) with baseline review.
- Keep quarantine lane healthy and reduce quarantined tests.
- Verify release hardening and changelog automation in real releases.

## Next (1-2 months)

- Add cloud device-farm presets and docs.
- Add security scanning lane and policy checks.
- Expand performance checks with targeted CI thresholds.

## Later (Quarterly)

- Accessibility test helpers and reporting support.
- Data lifecycle fixture adapters (seed/cleanup strategies).
- Governance dashboard for trends, ownership, and risk health.
