# Playbook: Framework Audit Checklist

- [ ] Config model is documented and strict mode behavior is clear.
- [ ] Core fixtures (`driver`, `waiter`, `actions`) remain stable.
- [ ] Failure diagnostics are complete and privacy-safe.
- [ ] Retry/xdist paths are explicitly tested.
- [ ] CI lanes cover core, optional extras, and quarantine.
- [ ] Release workflow enforces tag/version correctness.
